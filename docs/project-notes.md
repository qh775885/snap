# 视频截图神器 · 项目核心规范

## 1. 产品定位与核心诉求
本工具专注打造**极速、极简、高保真的本地视频截图与横截竖图利器**。

### 为什么放弃 AI 自动跟踪？
手动操作如果能做到极致便捷与顺手，人眼的审美构图与微表情捕捉远比笨重、死板的 AI 更加精准。软件不做无收益的 AI 膨胀，全部算力与精力集中在“极致的人机操控体验”。

### 两大核心交互生命线（必须死磕）
1. **丝滑快进/慢进（绝不卡、绝不跳）**：
   - 长按键盘步进时，画面必须像高刷放映机一样高速、连贯、均匀地一帧一帧滑过。
   - 杜绝画面卡死或突然跳走一大段，确保肉眼能够精准看清每一瞬间的动态细节。
   - 依赖“固定节拍 + seeked 门控”的精准帧控制机制。
2. **极速快门截图**：
   - 配合预设竖屏裁剪框（9:16 / 3:4 / 1:1），按键即瞬间定格出图。
   - 毫秒级响应，不打断预览节奏。

---

## 2. 技术架构与交付形态

- **交付形态**：**仅交付免安装纯绿色版（Portable）**，不再维护任何安装包。
- **架构演进（lite 路线）**：
  - **界面层**：保留精简的 React 19 + Tailwind 前端，纯净直接。
  - **宿主层**：系统 WebView2 + Tauri 2.0 (Rust)，彻底剥离 200MB 的 Electron 臃肿壳。
  - **解码层**：专用裁剪版 FFmpeg，剔除无用编码器，仅保留视频解码与高速管道抽帧能力。
  - **体积目标**：从 435MB 压缩到 25~30MB 左右。

---

## 3. 维护约束
- 优先轻量、稳定、低资源占用。
- 视频相关的临时文件随用随清。
- 界面坚持紧凑、沉浸、少按钮，一切为了操作手感服务。
