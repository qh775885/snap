# 视频截图神器 (Lite)

极速、极简、高保真的本地视频截图与横截竖图工具。

## 核心体验
- **丝滑步进**：高刷放映级逐帧快进/快退，长按连贯不卡顿、不跳帧，精准捕捉每一瞬。
- **横截竖图**：自由拖动/微调裁剪框（9:16 / 3:4 / 1:1），按键即刻定格裁切。
- **快门截图**：`S` 键 / 快捷操作毫秒级存图，自动保存并实时侧栏预览。
- **轻量绿色**：仅交付免安装纯绿色便携版，无冗余体积，开箱即用。

## 快捷操作
- `Space`：播放 / 暂停
- `S` / 鼠标右键：快门截图（含预设竖屏裁切）
- `←` / `→`：单帧/连跳步进（长按平滑走帧）
- `I` / `O`：标记起止截取区间
