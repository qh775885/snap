# 快门 (snap)

> **专精“横屏截竖图”与“极速清点”的本地高保真视频快门截图利器。**

基于 **Tauri 2.0 (Rust) + 系统 WebView2 + React 19 + Vite** 构建，完全去除臃肿依赖，免安装单文件仅 **22MB**，内存占用仅 **25MB**。

---

## ⚡ 核心设计与体验

1. **放映级丝滑步进**：鼠标侧键/方向键快进快退均匀连贯，绝不跳帧或卡顿，硬件加速直接捕捉毫秒级微表情。
2. **毫秒快门直裁**：支持全屏原比例截取，以及预设竖屏构图直裁（9:16 / 3:4 / 1:1 / 4:5），鼠标右键或 `S` 键瞬间完成抓取+直裁+写盘。
3. **靶场图库极速清点**：右侧双列网格完整原貌展示；键盘 `Del` / `Backspace` 键单张秒删废片；双击无缝进入全屏沉浸大图看图器。
4. **视频原生通吃**：支持 MP4 原生硬解与 MPEG-TS（集成 mpegts.js 零延迟解封装流式播放）。

---

## 🎮 操控指南

| 动作 | 触发方式 | 说明 |
| :--- | :--- | :--- |
| **快门截图** | **鼠标右键** / 键盘 `S` | 瞬间截取当前画面（原图或构图框直裁），零卡顿写盘 |
| **快进步进** | **鼠标侧键（前）** / 键盘 `→` | 单击进 1 帧，长按平滑递增加速 |
| **快退步进** | **鼠标侧键（后）** / 键盘 `←` | 单击退 1 帧，长按平滑倒退 |
| **播放 / 暂停** | 键盘 `Space` | 切换视频播放状态 |
| **秒删废片** | 键盘 `Del` / `Backspace` | 选中图片或大图模式下直接物理删除，自动切到下一张 |
| **沉浸看大图** | **双击缩略图** / 键盘 `Enter` | 进入全屏高清看图器（支持滚轮/方向键翻图） |
| **打开外部视频** | **直接拖拽文件入窗** / 顶部“打开” | 支持 MP4、TS、MKV、WebM 等格式 |

## 🛠 本地开发指令

项目强制统一使用 **`pnpm`** 管理依赖：

```bash
# 安装依赖
pnpm install

# 启动开发与热更新预览
pnpm dev

# 代码静态验证与快速打包自检 (约 3 秒)
pnpm verify

# 构建免安装纯绿色版 (产物位于 release/快门-免安装绿色版/)
pnpm build
```
