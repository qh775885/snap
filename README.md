# 快门 (snap)

极速、极简、高保真的本地视频取景与横截竖图工具。

## 核心体验
- **放映级丝滑步进**：高刷放映级逐帧快进/快退，长按均匀连贯，绝不卡顿、绝不跳帧，毫秒捕捉微表情。
- **快门直裁**：常驻横截竖构图框（9:16 / 3:4 / 1:1），按键瞬间完成抓取、裁剪与异步落盘。
- **靶场图库**：截图实时排列，一目了然；键盘流 `Del` 秒删单张，支持多选与批量清除废片。
- **免安装纯绿色版**：彻底移除 Chromium 冗余，基于系统 WebView2 + Tauri 2.0 (Rust) 构建，极度轻巧。

## 快捷操作
- `Space`：播放 / 暂停
- `S` / 鼠标右键：快门截图（含预设竖屏构图直裁）
- `←` / `→`：逐帧/连跳步进（长按平滑走帧）
- `Del`：靶场图库单张直删
- `I` / `O`：标记起止区间
